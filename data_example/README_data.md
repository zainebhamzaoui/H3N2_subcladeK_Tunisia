# Input data

This repository contains scripts used to analyze Tunisian A/H3N2 variant K HA sequences and contemporaneous global HA sequences.

Raw GISAID sequences are not redistributed in this repository. Users should download the corresponding datasets directly from GISAID according to its data-sharing terms.

Expected input files include:

- Tunisian HA FASTA file
- Global HA FASTA file collected between 1 December 2025 and 31 January 2026
- Nextclade HA output file in TSV format
- Metadata table containing sequence names, collection dates, countries, and regions

The scripts are provided to document and reproduce the analytical workflow used for figure generation and supplementary tables.
